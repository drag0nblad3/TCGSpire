# Boss support bodies

Seven distinct transparent 512×400 WebP assets for the bodies added with boss rules.
`BossSupportArt` maps stable enemy ids without promoting supports into lead bosses
or changing encounter data. `VirtualBossArt` supplies per-body idle and action
animation: opposing ledger vortices, cell pulses, broadcast waves, shield grid,
charge arcs, and mirror glints. Defeated bodies use the static art.

Created with built-in image generation. Prompt direction: crisp faceted virtual
creatures with dark polygon interiors, thin faction-color contours, transparent
negative space and no text or fog. Bear/Bull use opposing financial chart motifs;
Clone uses emerald scalpel limbs and a helix abdomen; Co-Anchor uses magenta antennae,
yellow wave ribbon and equalizer tails; Aegis uses silver shield vanes; Capacitor uses
violet twin prongs and a cyan charge core; Mirror uses lilac shards and a reflected face.
Clone and Co-Anchor were edited to remove haze while preserving their bodies.
`provenance.json` records final source names, hashes and packing. Original generated
images are preserved. Packing only crops transparent padding, resizes proportionally
and centers each body with a clear margin; it does not synthesize or alter artwork.

`tools/preview_boss_support.gd` renders 36 review frames with the production renderer.
The Spore Pod card is separately illustrated in the established Field Service ink,
ivory and green style at `assets/cards/spore_pod.webp` (448×168). Its source is
`exec-a0e9f1d5-7ed1-4c7e-9b03-0a3ba2ec690e.png`; it depicts a cracked bioelectronic
capsule with a grub inside. No gameplay rules or numbers change.
